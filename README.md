## 概要

SPMレジスタ設定ソフト(Register Configuration Tool)。\
RS485ベースのModbusライクのプロトコルSPM-Modbusで接続する。\

## 機能

* Input Register、Holding Registerの読み書き
* デバイスプロファイルからレジスタの自動認識
* デバイスアドレスの検索
* サイクリックレジスタのテスト
* パラメータの保存、読み出し
